# person_info/manager 说明

本目录用于承载对 `src/person_info/person_info.py` 中 `PersonInfoManager` 的拆分草稿，当前阶段仅做代码结构预拆分，尚未接入主流程：

- **来源**：基于 `src/person_info/person_info.py` 的功能拆解（常量/ID 生成、数据仓储、取名服务、门面服务）。原文件仍然是唯一生效的实现。
- **目的**：提前梳理职责边界，降低后续重构接入成本，同时便于针对单一职责做单元测试或接口演化设计。
- **组成**：
  - `constants.py`：默认字段、JSON 序列化字段列表、`get_person_id` 纯函数。
  - `repository.py`：CRUD 封装与缓存失效处理。
  - `naming_service.py`：LLM 取名流程与唯一名生成。
  - `service.py`：作为门面组合仓储与取名，提供与旧管理器对应的业务方法。
  - `__init__.py`：集中导出上述组件。
- **状态**：目前未在项目其他模块中引用；重构验证前请继续使用原 `person_info.py`。
- **后续接入建议**：
  1) 在旧管理器内部逐步改为调用 `PersonInfoService`，确保行为一致后再替换对外引用。
  2) 为关键路径补充集成测试（创建/更新/查询、取名去重）。
  3) 校验缓存 key 兼容性与 LLMRequest 复用，避免重复实例化。
